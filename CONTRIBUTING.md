# Contributing

1. Check the package isn't already listed.
2. Add it to the most relevant section, alphabetically within its table.
3. One line: `[owner/repo](url) | Purpose — under ~12 words`.
4. Only actively maintained packages (commit/release within the last ~12 months), unless explicitly noted as historical/deprecated with a pointer to the replacement.
5. Open a PR. Keep PRs to one section/one theme at a time — easier to review.

## Removal criteria

A package gets removed (or marked deprecated) if:
- The repo is archived by its owner, or
- README explicitly says "no longer maintained" / points to a replacement, or
- No commits in 24+ months and known incompatibility with current Laravel major version.
